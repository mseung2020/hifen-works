# 아모레퍼시픽 앰플·세럼 데이터 인사이트

앰플·세럼 7개 브랜드(메디큐브·메디힐·아누아·토리든·웰라쥬·성분에디터·이니스프리)의 **발행량-올리브영 랭킹 상관관계**와 **참여지표(조회수·좋아요·댓글) 랭킹**, **30일 이동평균 대비 발행 추세**를 여러 각도로 분석한 데이터 인사이트 작업입니다. 이니스프리의 7월 레티놀 앰플 신제품 출시를 계기로 시작해, 경쟁 브랜드 전략 비교 → 이니스프리 자체 채널효율 벤치마킹까지 이어집니다.

- **분야:** 데이터 분석
- **결과물 형태:** 3장 구조 분석 리포트(MD) + 인터랙티브 HTML 차트 7종 + 데이터 요약
- **핵심 발견:**
  - 발행량-랭킹 상관관계 **-0.88(5개월 평균)/-0.86(7월)** — 발행량 200건이 상위권 진입 문턱
  - 조회수·좋아요·댓글 같은 참여지표는 랭킹과 뚜렷한 관계가 없음
  - 토리든은 유가 집중 투입 시점과 순위 반등 시점이 정확히 겹쳤지만, 메디큐브는 발행량 1위인데도 순위 하락을 막지 못함(나노·마이크로 인플루언서 위주 저비용 물량전)
  - 이니스프리는 리뉴얼 이후 순위를 빠르게 회복했지만, 인스타 유가 의존도(67%)가 높고 채널당 실제 도달률(조회수÷팔로워)이 메디큐브보다 3~13배 낮아 비용 효율 개선 여지가 있음
