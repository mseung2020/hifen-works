# 데이터 요약

이 프로젝트의 원천/중간 데이터는 `data/`(90MB) + `data2/`(41MB) 총 131MB로, GitHub에는 담기 어려운 규모입니다. 최종 리포트(`REPORT.md`)와 리포트가 참조하는 차트(`차트결과물/`)만 레포에 담고, 원천/중간 데이터는 아래로 요약합니다. 리포트에서 실제로 언급된 핵심 요약 테이블 3개는 `data_요약/`에 원본 그대로 포함했습니다.

## 제외된 원천/중간 데이터 (`data2/`, 41MB)

`data2/README.md`(레포에 보존)에 따르면 이 폴더는 노션 "브랜드/제품별 랭킹 및 총발행량" DB의 **총발행량** 값이 만들어지기까지의 별도 비용/발행량 계산 파이프라인입니다.

1. **원본 태깅**: `유튜브 유가.csv`, `인스타 유가.csv` — 브랜드별 유튜브 영상/인스타 포스트의 유가(광고)·무가 태깅 원본
2. **브랜드별 집계**: `브랜드별비디오_최근12개월/`(37MB), `브랜드별포스트_최근5개월/`(632KB)
3. **SKU 매핑**: `product_id_매핑표.csv`, `mapping_v2_961.csv` — 같은 제품의 여러 판매 옵션(SKU)을 대표 제품으로 묶는 매핑표
4. **월별 집계**: `제품별_월간_ppl_비디오포스트_집계.csv` → `제품별_월간_ppl_비디오포스트_집계_정리.csv`(총발행량의 직접 출처, 3~7월 월별 video/post × 유가/무가 건수)
5. **비용 계산**: `비용계산.py` — `비용 산정.md`(7월_brand_ppl_cost 참고) 로직으로 콘텐츠 단위 예상비용 계산 → `총발행량_콘텐츠단위_비용산정_결과.csv`(884KB) → 브랜드 단위로 합산한 `브랜드별_예상비용_요약.csv`(→ `data_요약/`에 포함)
6. 그 외: `6개브랜드_디엠수_쿼리.csv`(DM수 비교), `이니스프리_비교군_참여지표_쿼리.csv`(3장 채널효율 비교의 원본 쿼리 결과)

> 분석 코드(`비용계산.py`, `split_*_by_brand.py`, `tag_brand_and_drop_desc.py`)와 중간 산출물은 원본 작업실에 보존되어 있으며, 이 레포에는 읽기 좋은 최종 리포트·차트와 핵심 요약 테이블만 담았습니다.
