# 인사이트 생성 LLM 프롬프트 — 스토리라인 카드뉴스 v2 (6개 노드)

프로즈(LLM 텍스트)를 6개 슬롯으로 운용한다. 데이터 근거(표·막대·게이지)는 결정적 Code 노드가 그리고,
LLM은 "시각적으로 특별한 자리"의 서술만 채운다. 6개 노드는 http-request(JSON)에만 의존 → **병렬 실행**.

권위 있는 프롬프트 원문은 `build_storyline_workflow.py` 안에 상수로 들어 있고(YML 생성 시 그대로 임베드),
이 문서는 사람이 읽는 요약 스펙이다.

| 슬롯 | 위치 | 성격 | 출력 형식 |
|---|---|---|---|
| `lead_headline` | 표지 헤드라인 | 자유 60:근거 40 | 한 줄 18~34자, `*강조구*` 마커 1개 허용 |
| `identity_claim` | 정체성 패널 | 자유 55:근거 45 | `CLAIM: …` / `BODY: …` 2줄 (BODY 180자) |
| `ai_highlights` ★ | AI PICK 3장(컬러 카드) | **자유 90:근거 10** | `HIGHLIGHT: 제목 \| 본문(3~4문장) \| 한줄임팩트` ×3 |
| `audience_persona` | 오디언스 패널 eg | 자유 80:근거 20 | 1문단 3~4문장 220자 |
| `content_read` | 성과 패널 win | 근거 60:자유 40 | 1~2문장 160자 (협찬vs오가닉 유일 해석) |
| `closing` | 마무리 패널 | 종합 | 2~3문장 240자, 캠페인 포맷 1~2개 제안 |

## 공통 원칙 (모든 프롬프트 앞)
- 숫자 재낭독 금지(표에 이미 있음), 최대 1~2개만 "그래서 무슨 뜻"일 때 인용.
- 데이터 없는 사실 날조 금지. 단 해석/추론/상상은 역할.
- 문체 '~습니다'체 통일(단 lead_headline·ai 제목은 명사구 헤드라인 톤 허용).
- 협찬 아닌 콘텐츠는 "오가닉/비협찬"("유기농" 금지).
- **마크다운(#, -, *, ** 등) 금지** — 렌더러 없어 기호가 노출됨. 단 지정 슬롯의 `*강조구*` 마커는 예외(Code가 형광펜 span으로 변환·누출 방지).

## ai_highlights (핵심)
크리에이터마다 **강조할 3가지를 스스로 선정**(고정 슬롯 아님). 세 포인트는 서로 다른 각도(화자 개성 / 콘텐츠·협찬
방식 / 성장·오디언스 관계 등). 각 줄 3부분을 ` | ` 로만 구분: **제목**(30자, `*마커*` 1개 가능) · **본문**(3~4문장,
230자) · **한줄 임팩트**("그래서 광고주에게 무슨 뜻인가" 결론 1문장). 자유도 90이지만 데이터가 뒷받침하는 것만.

## 배선
`lead_headline` `identity_claim` `ai_highlights` `audience_persona` `content_read` `closing` (6개) → 병렬
→ `code_assemble_html`(스토리라인 v2) 가 JSON + 6개 텍스트로 최종 HTML 조립.
